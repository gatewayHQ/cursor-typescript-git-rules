# Cursor TypeScript + Git Commit Rules

Two free [Cursor](https://cursor.com) project rules (`.mdc`) from the ShipReadyAgents rules pack:

1. **typescript** — strict TypeScript, boundary validation, named exports
2. **git-commits** — Conventional Commits, ask before committing

## Install

```bash
mkdir -p .cursor/rules
cp .cursor/rules/*.mdc /path/to/your-project/.cursor/rules/
```

Or copy from this repo’s `.cursor/rules/` folder into your project.

Open **Cursor → Customize → Rules** to confirm they appear.

## Full pack

This is a **free sample (2 of 10)**. The [Cursor Rules Pack](https://shipreadyagents.com/templates/cursor-rules-pack) also includes core workflow, Next.js, React, Python, Tailwind, testing, API security, and Supabase rules plus an installer.
